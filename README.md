# Entity Model Features — EMF Override API

[![Download Latest](https://img.shields.io/github/v/release/quarkakatsukishine/entity-model-features-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/quarkakatsukishine/entity-model-features-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Provides OptiFine-style Custom Entity Model (CEM) support on Fabric and NeoForge without OptiFine.

![Entity Model Features — EMF Override API Preview](https://cdn.modrinth.com/data/4I1XuqiY/images/ba682dbb4d4ff5df8900987e6d8e86f4997fc119_350.webp)

## Features

- OptiFine CEM format support without OptiFine
- JSON-based entity model overrides via resource packs
- Works with Entity Texture Features for full parity
- Vanilla and modded entity model override support
- Performance-focused, works alongside Sodium

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
